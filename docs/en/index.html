WHAT TRAINING MEANS

Learn to choose
by your rules.

Fine-tuning adapts an existing model using examples with a correct answer. Julia chooses from the options you define; it does not write free-form responses.

01

Define the decision

Write the question and what each category means. For example: urgent, normal and review.

02

Teach with examples

Provide texts and the correct category. The AI agent helps organize the file and spot ambiguities.

03

Train and compare

The tool adapts Julia and checks its behavior on examples kept separate from training.

↳

The original model is preserved. The result is a fine-tuned copy you can test before deciding whether to use it.

COMMON QUESTIONS

Before you start.

Do I need a powerful graphics card?

Not for the initial setup: CPU training has been tested. Time and memory requirements depend on dataset size and text length. The agent will check the available resources.

Does training happen on this page?

No. This page explains the process and provides instructions. Training runs on your computer using Python and PyTorch.

What can this version learn?

Selection decisions: classifying text into categories you define, such as priority or the responsible department. It does not turn Julia into a chatbot or add free-form text generation.

Does my data leave my computer?

The trainer runs locally and does not send examples to a training API. If your AI assistant is an external service and you give it file access, how that data is handled depends on that service.

Does the AI decide which answers are correct?

It can suggest examples and flag inconsistencies. Rules and labels must reflect your decisions. An invented or ambiguous answer can teach the wrong behavior.

Do I need to install the workspace?

It is optional. The tool works on its own. The workspace stores instructions, procedures and evidence so another AI session can continue the work.
