El fine-tuning ajusta un modelo que ya existe mediante ejemplos con una respuesta correcta. Julia elige entre las opciones que tú defines; no escribe respuestas libres.

DUDAS HABITUALES

Antes de empezar.

¿Necesito una tarjeta gráfica potente?

No para la ruta inicial: se ha probado el entrenamiento por CPU. El tiempo y la memoria necesarios dependen del tamaño del dataset y de la longitud de los textos. El agente comprobará los recursos disponibles.

¿Se entrena dentro de esta página?

No. Esta página explica y entrega las instrucciones. El entrenamiento se ejecuta en tu equipo mediante Python y PyTorch.

¿Qué puede aprender esta versión?

Decisiones de selección: clasificar un texto entre las categorías que defines. Por ejemplo, prioridad o departamento responsable. No convierte Julia en un chatbot ni le añade generación de texto libre.

¿Mis datos salen de mi equipo?

El entrenador trabaja localmente y no envía los ejemplos a una API de entrenamiento. Si tu IA asistente es un servicio externo y le das acceso a los archivos, su tratamiento de esos datos depende de ese servicio.

¿La IA decide qué respuestas son correctas?

Puede proponer ejemplos y señalar inconsistencias. Los criterios y las etiquetas deben reflejar tus decisiones. Una respuesta inventada o ambigua puede enseñar el comportamiento equivocado.

¿Necesito instalar el workspace?

Es opcional. La herramienta funciona sola. El workspace permite conservar instrucciones, procedimientos y evidencia para que otra sesión de IA pueda continuar el trabajo.
